Loading Data from Hugging Face

Access thousands of free datasets for NLP, sentiment analysis, and machine learning. Learn how to search, load, and explore them in your notebooks.

What is Hugging Face?

Hugging Face is an open-source platform hosting:

  • Pre-trained machine learning models
  • Thousands of free datasets for NLP and other ML tasks
  • Community resources and tutorials

For this course, we use their Datasets library to download and work with real-world data without storing huge files locally.

Installation

The datasets package is already in your virtual environment (installed in Python Virtual Environments), but if you need it:

pip install datasets

Basic Usage: Load a Dataset

Step 1: Import the library

from datasets import load_dataset

Step 2: Load a dataset

dataset = load_dataset("imdb")
print(dataset)

Output:

DatasetDict({
    train: Dataset({
        features: ['text', 'label'],
        num_rows: 25000
    })
    test: Dataset({
        features: ['text', 'label'],
        num_rows: 25000
    })
    unsupervised: Dataset({
        features: ['text', 'label'],
        num_rows: 50000
    })
})

Step 3: Explore the data

# Look at the structure
print(dataset['train'][0])

# Get a sample
sample_review = dataset['train'][0]['text']
print(sample_review[:200])  # First 200 characters

Common Datasets for INFO 4360

IMDB Movie Reviews

load_dataset("imdb")

25,000 positive and negative movie reviews for sentiment classification. Used in Class 2 and 3.

Stanford Sentiment Treebank (SST)

load_dataset("sst")

Movie reviews with fine-grained sentiment labels (5 levels, from negative to positive).

AG News

load_dataset("ag_news")

News headlines classified into 4 categories. Good for text classification practice.

YELP Reviews

load_dataset("yelp_review_full")

Restaurant reviews with ratings (1-5 stars). Longer documents than IMDB.

Working with Datasets

Filter to a subset

# Get only the first 1000 reviews
dataset_small = dataset['train'].select(range(1000))

# Filter to positive reviews only
positive = dataset['train'].filter(lambda x: x['label'] == 1)

Access columns

# Get all labels
labels = dataset['train']['label']

# Get all text
texts = dataset['train']['text']

Convert to pandas

import pandas as pd

df = dataset['train'].to_pandas()
print(df.head())

Finding Datasets

  1. Go to huggingface.co/datasets
  2. Search by task (e.g., "sentiment analysis," "text classification")
  3. Click a dataset to see its documentation and sample data
  4. Copy the load command (usually shown in the docs)
💡 Tip: Most datasets are large, so start with a small subset using .select(range(100)) to test your code before running on the full dataset.

Common Issues

"No dataset named..."

The dataset name is misspelled or doesn't exist. Check the Hugging Face Datasets page for the exact name.

Download is slow

Datasets are downloaded to your machine the first time. They're cached, so subsequent loads are instant. Be patient on first load.

"Can't find split..."

Not all datasets have 'train', 'test', and 'validation' splits. Check the dataset's documentation to see what splits it has.

# See available splits
print(dataset.keys())

Best Practices

  • Start small: Test your code on 100 rows before the full dataset
  • Check the docs: Each dataset has different fields and splits. Read the documentation
  • Explore first: Look at a few examples before processing
  • Use to_pandas(): If you're more comfortable with pandas, convert and work there
