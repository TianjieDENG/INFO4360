Writing AI Use Logs

Document how you use AI tools in your coursework. This is required for most weekly homework assignments.

What is an AI Use Log?

An AI Use Log is a brief record of when, what, and why you used an AI tool (like GitHub Copilot, Claude, ChatGPT, etc.) while working on an assignment.

It's not about hiding AI use — it's about transparency and reflection. It helps you notice your own workflow and me understand how you're learning.

What to Include

Field What to write
When Time or phase of work (e.g., "while debugging," "at the start," "mid-project")
What tool Which AI you used (GitHub Copilot, Claude, ChatGPT, etc.)
What task What specific problem you asked it to help with (e.g., "write a function to tokenize text," "explain this error message")
Why Why you turned to AI (stuck, wanted to check your work, learning new syntax, etc.)
What you learned One sentence: what did this teach you?

Format Options

Choose whichever format works for you:

Option A: Markdown list (in a notebook markdown cell or .md file)

# AI Use Log — Homework 2

## Entry 1
- **When:** While writing the tokenization function
- **Tool:** GitHub Copilot
- **Task:** Generate a function that removes punctuation
- **Why:** I wasn't sure of the exact syntax for list comprehensions
- **Learned:** Using `[char for char in string if char not in punctuation]` is cleaner than a loop

## Entry 2
- **When:** Debugging the output
- **Tool:** Claude (via Claude Code)
- **Task:** Explain why my word frequency counts didn't match the expected output
- **Why:** Silent bug — no error message, just wrong numbers
- **Learned:** I wasn't lowercasing before counting. Small detail, big impact.

Option B: Inline comments in code

# AI Use Log entries:
# 1. Used Copilot to write the tokenize() function — wasn't confident with regex syntax
# 2. Asked Claude to debug word frequency counts — discovered I needed .lower() before counting
# 3. Used ChatGPT to understand pandas groupby — just exploring, not part of the assignment

Option C: Word document (if submitting in Word)

Just a simple bulleted list with the fields above. Plain and readable.

Example Entries

✓ Good Example

Tool: GitHub Copilot
Task: Write a function to filter stopwords from a token list
Why: I had the logic right but wasn't sure of the exact Python syntax
Learned: Copilot showed me I could use a list comprehension with an `if` condition, which is much cleaner than a loop.

✗ Too vague (avoid this)

Tool: ChatGPT
Task: Homework help
Why: I was stuck

← Too vague. What exactly did you ask? What was the task? What did you learn?

Why This Matters

This isn't about compliance — it's about awareness.

When you log your AI use, you notice patterns: Am I asking for help too early? Am I learning from the AI's explanations, or just copying code? Am I using AI for the right things (syntax, ideas) vs. the wrong things (letting it solve the whole problem)?

That reflection is where learning happens.

Requirements

  • Include one entry for each time you use AI — even quick questions count
  • Be honest: If you used AI, say so. If you didn't, you don't need a log
  • Be specific: "I asked Copilot to write a tokenizer function" beats "I used Copilot"
  • Submit it with your homework: Usually in the same file or as a separate "AI Use Log" section
  • No log = honest work: If you didn't use AI, you don't need to write anything — just say "No AI use on this assignment" or leave it blank

Questions?

If you're unsure whether something counts as "AI use," ask. Better to log it and be transparent.
