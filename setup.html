Get your machine ready

Six steps to a working Python + VS Code setup for the course. The toggle above switches every instruction below between Windows and Mac — pick your laptop once and read straight through.

  • VS Code, with Python and Jupyter notebook support
  • A Python install that any terminal on your machine can find
  • GitHub Copilot, set up for weekly homework help
  • Git and Claude Code, ready ahead of the group project (optional for now)
  1. 1

    Install VS Code

    Required~5 min
    1. Go to code.visualstudio.com and click Download for Windows.
    2. Run the installer and accept the license agreement.
    3. On Select Additional Tasks, leave Add to PATH checked — it's on by default, and you'll want it for the code command later.
    4. Click through Install, then Launch.
    1. Go to code.visualstudio.com and click Download for Mac.
    2. Unzip the download, then drag Visual Studio Code.app into Applications.
    3. Open it from Applications. The first time, right-click → Open — it's from outside the App Store.
    4. Open the Command Palette (⌘⇧P), run "Shell Command: Install 'code' command in PATH."

    Verify

    code --version

    Run this in VS Code's own terminal (Terminal → New Terminal). You should see three version lines, not an error.

  2. 2

    Install Python

    Required~10 min
    Don't skip this

    On Windows, the Python installer has a checkbox — Add python.exe to PATH — sitting unchecked at the bottom of the very first screen. It's the single most common setup mistake in this course. If a terminal later says python is not recognized as an internal or external command, this is almost always why.

    "On PATH" just means: your terminal searches every folder in one long list whenever you type a command. This is what that list looks like on a real Windows machine, truncated:

    ...;C:\Users\you\AppData\Local\Programs\Python\Python312\;C:\Users\you\AppData\Local\Programs\Python\Python312\Scripts\;...

    Checking the box adds Python's two folders to this list. Skip it, and the terminal never finds python.

    1. Go to python.org/downloads and click the yellow Download Python 3.x.x button.
    2. Run the installer.
    3. Check "Add python.exe to PATH" at the bottom of the first screen (see above).
    4. Click Install Now.
    5. Close any terminal or VS Code windows already open, then reopen them — PATH changes only apply to new terminals.
    1. macOS doesn't ship a current python3 by default. Go to python.org/downloads and download the macOS installer.
    2. Run it and click through the defaults.
    3. Open a brand-new Terminal window — not one left open from before.

    Verify

    python --version
    pip --version
    python3 --version
    pip3 --version

    On Mac the commands are python3 and pip3, not python and pip — worth remembering when a tutorial online was written for Windows.

  4. 4

    Set up GitHub Copilot

    Required~10 min

    Tentatively, this is the assistant you'll use for weekly homework — start now, since student verification can take a day or two. We may switch to Claude Code later in the quarter.

    1. If you don't already have one, create a GitHub account at github.com using a permanent personal email (Gmail, Outlook, etc.) — this becomes your account's primary login and lasts beyond your student email.
    2. Once created, add your student email as a secondary email in github.com/settings/emails.
    3. Apply for the GitHub Student Developer Pack at education.github.com/pack using your student email and enrollment proof. You can verify with your secondary email.
    4. Once approved, Copilot Pro turns on automatically — check github.com/settings/copilot for "Active."
    1. In VS Code, open the Extensions view (Ctrl+Shift+X) and install "GitHub Copilot" and "GitHub Copilot Chat" (publisher: GitHub).
    2. Sign in when prompted — bottom-right notification, or Command Palette → "GitHub Copilot: Sign in."
    1. In VS Code, open the Extensions view (⌘⇧X) and install "GitHub Copilot" and "GitHub Copilot Chat" (publisher: GitHub).
    2. Sign in when prompted — bottom-right notification, or Command Palette → "GitHub Copilot: Sign in."

    Verify

    Open a .py file, start typing a function, and pause — grey ghost-text suggestions should appear. Or open Copilot Chat from the sidebar and ask it a question.

    Approval still pending? Copilot's limited free tier works while you wait; full access turns on the moment your Student Pack is approved. The Chat model picker also lets you switch to a Claude model once it's available.
  5. 5

    Install Git

    Optional~5 min

    Skip this for now if you'd like — you won't need it until the group project.

    First, check whether you already have it

    git --version

    Run this in VS Code's terminal (Terminal → New Terminal). If it prints a version number, Git is already installed — skip straight to Set your identity below. If it says not recognized or command not found, install it first.

    Install (Windows)

    1. Go to git-scm.com/download/win, download the installer, and run it.
    2. Click Next through the screens. Two of them matter:
    3. "Choosing the default editor used by Git" → pick "Use Visual Studio Code as Git's default editor."
    4. "Adjusting your PATH environment" → leave the recommended middle option selected: "Git from the command line and also from 3rd-party software." This is what makes git work in every terminal.
    5. Finish the install, then close VS Code completely (every window) and reopen it — a terminal that was open during the install won't see Git until then.

    Install (Mac)

    1. If git --version reported it's missing, macOS has already offered to install the Command Line Tools — accept that prompt. (Or run xcode-select --install to trigger it.)
    2. When it finishes, close VS Code and reopen it, then run git --version again.

    Set your identity (one time)

    Paste both lines into the terminal. Use the name and email you want stamped on your commits — the email should be one attached to your GitHub account.

    git config --global user.name "Your Name"
    git config --global user.email "you@du.edu"

    Verify

    git --version

    A version number means you're done.

  6. 6

    Install Claude Code

    Optional~5 min

    Claude Code is an AI coding assistant that runs in a terminal, including the one built into VS Code. We'll (tentatively) use it for the group project, so this can wait if you'd rather install it later.

    Install (PowerShell)

    irm https://claude.ai/install.ps1 | iex

    Install (Terminal)

    curl -fsSL https://claude.ai/install.sh | bash

    Verify

    claude --version

    The first time you run claude inside VS Code's terminal, it offers to install a companion Claude Code VS Code extension — accept it for inline diffs and a sidebar panel. You can also add it by hand from the Extensions view (search "Claude Code", publisher: Anthropic).

    Don't connect an account or paste an API key yet. Workspace keys for the project go out separately, closer to when you'll actually need them.

Checklist

  • code --version prints a version
  • python --version (or python3) prints a version
  • Python and Jupyter show up in VS Code's Extensions view
  • Copilot shows ghost-text suggestions in a .py file
  • git --version prints a version — optional
  • claude --version prints a version — optional

If something's not working

"python is not recognized as an internal or external command" (Windows)
You skipped the PATH checkbox. Rerun the python.org installer, choose Modify, check Add python.exe to PATH, then open a brand-new terminal.
Typing "python" opens the Microsoft Store (Windows)
A store alias is intercepting the command. Go to Settings → Apps → Advanced app settings → App execution aliases and turn off the python.exe / python3.exe entries.
"command not found: code" (Mac)
Run "Shell Command: Install 'code' command in PATH" again from the Command Palette (⌘⇧P).
VS Code can't find your Python
Open the Command Palette (Ctrl/⌘+Shift+P) → "Python: Select Interpreter" → pick the one matching the version your terminal showed in Step 2.
